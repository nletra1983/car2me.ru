# Справочник: веса от клиента

Детализация для `SKILL.md`. Веса **не** берутся из эталонного кейса — только из ответов формы.

## Источники весов (приоритет)

1. **Матрица критериев** (стр. 3) — основной источник, ~85% решения
2. **Топ-3 сценария** «без чего не подойдёт» — бонус к связанным критериям
3. **Рамки и техника** — hard filters, не веса (кроме согласования ниже)
4. **Свободный текст** — ручной разбор → filter или корректировка веса

## Шкала → баллы

Ответ на каждый из 16 вопросов «Один вариант» в Яндекс.Формах:

| Не важно | Желательно | Важно | Критично |
|----------|------------|-------|----------|
| 0 | 1 | 2 | 3 |

## Расчёт

```
1. score[c] = балл из матрицы для каждого критерия c
2. Для каждого из топ-3 сценариев s:
     для каждого связанного критерия c: score[c] += 0.5
3. weight[c] = score[c] / sum(score) × 100
```

Если `sum(score) == 0` — не генерировать отчёт.

## Оценка модели по критерию (1–5)

| ID | На что смотреть |
|----|-----------------|
| budget | Влезает ли под ключ в лимит клиента |
| engine_reliability | Ресурс мотора, типичные болезни, атмосфер vs turbo |
| repair_ru | Запчасти, сервис, распространённость |
| clearance | мм клиренса, тип подвески |
| transmission | AT/CVT/DCT, надёжность версии |
| range_km | бак ÷ реальный расход |
| space | объём багажника, место задним |
| dynamics | разгон, обгоны с нагрузкой |
| highway_comfort | шум, жёсткость, круиз |
| sleep_in_car | длина салона, flat fold |
| resale | ликвидность канала + руль + город клиента |
| economy | л/100 км; для гибрида/электро — расход и логистика зарядки |
| winter | прогреv, аккум, мотор |
| safety | ABS/ESP/подушки в типичной комплектации |
| lhd | RHD/LHD доступность |
| comfort_features | климат, подогревы, камера |

**Итоговый балл модели:** `Σ(оценка_1_5 × weight) / Σ(weight) × 20` → /100.

## Hard filters (не веса)

Из рамок и техники — применять до scoring:

| Условие | Действие |
|---------|----------|
| Только левый руль (рамки) | RHD out (если не «если сильно лучше») |
| lhd = Критично в матрице | RHD out |
| Только автомат | MT out |
| ≥5 дверей | 3-door out |
| До 160 л.с. (техника) | >160 out или пометка утиль |
| Избегать DCT | DCT out или «осторожно» |
| Серый parallel «нет» | out |
| Китай «нет» | CN out |
| Табу-марки | out |
| Максимальный возраст (техника) | год лота > лимита → out или «осторожно» + конфликт |
| «слишком старое» / «древнее» в тексте | max_age ≈ 5–7 лет, указать допущение в отчёте |
| Максимальный пробег (техника) | out или «осторожно» |
| «не вариатор» / prefer AT в тексте | CVT-only поколение → не «лидер»; AT только если есть у **свежего** поколения |

## Тип топлива / силовая установка (стр. 5, необязательно)

| Ответ | Действие |
|-------|----------|
| Только электро / PHEV | Фильтровать модели без гибрида/EV; JP e:HEV, CN PHEV |
| Только газ (ГБО) | В shortlist: редко с ввоза; честно — «обычно ставят после покупки» или out |
| Только дизель | Out бензиновые; KR/JP/CN дизель — узкий пул |
| Только бензин | Out гибриды/EV если явно не выбраны |
| Гибрид в списке | Включать e:HEV (Vezel, Yaris Cross), CN PHEV |
| «Без разницы» | Не фильтровать |

Марка бензина (92/95) **не спрашиваем** — упоминать в отчёте только если у модели турbo и это типичная рекомендация.

## Частота «сложного» (стр. 2)

Не меняет веса. Используется в тексте отчёта: «раз в неделю по грунтовке» vs «раз в год».

## Жёсткость бюджета

| Ответ | Поведение при scoring budget |
|-------|------------------------------|
| Жёстко | >105% лимита → «не влезает» |
| Мягко | до 110% → «на грани» |
| Гибко | показать идеал выше с доплатой |

## Конфликты

| Ситуация | Решение |
|----------|---------|
| Перепродажа «да» в рамках, но «Не важно» в матрице | Доверять матрице; в отчёте одной фразой упомянуть |
| lhd «Критично», но «правый если лучше» в рамках | Hard filter для shortlist; RHD в «осторожно» |
| Критично бюджет + гибкий лимит | Scoring строгий, в тексте — допустимый перерасход |
