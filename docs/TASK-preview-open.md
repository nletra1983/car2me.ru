# Задача: превью отчёта — тап открывает PNG на этой же странице

Сделать **только это**. Не рефакторить лендинг, не трогать кейс автора, оплату, форму, оферту.

**Вместо** [TASK-preview-scroll.md](TASK-preview-scroll.md) (скролл 1508px в маленькой рамке на мобилке отвергли). То не выкладывать.

**Не открывать** картинку в новой вкладке и **не** уводить на другой URL: человек может не вернуться на лендинг.

## Зачем

Люди зумят весь сайт, чтобы разглядеть матрицу. Нужно увеличить **на этой же странице**.

## Для пользователя

- На лендинге тизер: картинка **в ширину колонки** (`width: 100%`), рамка и рваный край. Не 1508px в окне 280px.
- Тап по картинке (не по ссылкам PDF) открывает **оверлей на весь экран**, лендинг под ним остаётся. URL не меняется (можно `#`, без новой вкладки).
- В оверлее картинка `content/preview.png` крупно: ширина файла ~1508px, внутри оверлея скролл/перетаскивание (весь экран, не виджет 280px). Крестик, тап по фону, Escape — закрыть, снова лендинг на том же месте.
- Подсказка на тизере, что можно нажать («Нажмите, чтобы увеличить»).
- PDF «Смотреть полный пример» + `download` — как сейчас.

## Метрика

- **`preview_open`**: открыл оверлей.
- **`cta_case`**: клик PDF, без изменений.
- **`preview_scroll`**: убрать из кода.

После выкладки: в кабинете JS-событие `preview_open`. `preview_scroll` не заводить.

## Как делать

- Файлы: `index.html`, `metrika.js`.
- Откатить ширину тизера на `width: 100%`.
- Оверлей: достаточно `<dialog>` или `position: fixed` на весь экран. Без библиотек, без PDF.js, без щипка «как в фотоприложении».
- Не использовать `target="_blank"`, не `location` на `preview.png`.
- Клик по тизеру не должен считаться `cta_case`.

## Не делать

- Новая вкладка / переход на PNG или PDF вместо оверлея.
- Снова 1508px внутри маленькой рамки тизера.
- Щипок-библиотека, PDF.js.
- Снимать `download` у PDF.
- Деплой без просьбы.

## Готово когда

- [ ] Тизер на мобилке — таблица в ширину колонки, не два огромных столбца.
- [ ] Тап открывает просмотр на **этой** странице; вкладок не прибавляется; закрытие возвращает к лендингу.
- [ ] В оверлее можно проскроллить матрицу (места по высоте — экран, не 280px).
- [ ] PDF → `cta_case`; оверлей → `preview_open`; `preview_scroll` нет.
- [ ] Запись в `docs/SESSION-LOG.md`.
- [ ] Локально ~375px и десктоп.
