# REQ-002 — Система включает метрику

**Статус:** draft  
**Контур:** as-is (код) · target — сверить с [REQ-003](REQ-003.md) и юристом

Связано с [REQ-003](REQ-003.md): одна правда по загрузке Метрики, не два противоречащих правила.

## Предварительные условия

Счётчик Яндекс Метрики установлен на сайте (`metrika.js`, ID задан).

## Поведение

### As-is (код `metrika.js`)

- Пользователь переходит на сайт
- Система загружает Яндекс Метрику при загрузке страницы **независимо** от ответа в cookie-баннере

### Target (текст `privacy.html` + согласование с юристом)

- Счётчик аналитики загружается **только после** согласия «Принять» в баннере ([REQ-003](REQ-003.md))
- При «Только необходимое» / без согласия — аналитический счётчик не загружается (если юрист не потребует иного минимального режима)

## Acceptance criteria

- [ ] Зафиксирована **одна** согласованная модель: либо «Метрика при любом заходе» (as-is код), либо «Метрика только после Accept» (как в политике) — и код, и `privacy.html`, и REQ-002/003 совпадают
- [ ] Модель проверена с юристом
- [ ] После выбора модели: поведение на проде соответствует выбранной правде при любом переходе на страницы с подключённым `metrika.js`
