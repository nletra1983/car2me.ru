# REQ-004 — Пользователь оплачивает услугу

**Статус:** draft  
**Контур:** as-is

## Предварительные условия

Пользователь находится на сайте и видит блок оплаты.

## Поведение

Пользователь выбирает удобный для него вариант оплаты: 1) QR-код, 2) ссылка на оплату, 3) перевод по СБП.

### QR-код

- Пользователь использует телефон для считывания QR-кода и оплачивает услугу через мобильное устройство

### Ссылка на оплату

- Пользователь кликает по ссылке
- Система открывает функционал оплаты от Сбербанка в новой вкладке

### Перевод по СБП

- Пользователь видит контакт телефона для перевода по СБП
- Пользователь оплачивает в банковском сервисе (осуществление оплаты нашим сервисом не контролируется)

## Acceptance criteria

- [ ] Пользователю доступны все опции оплаты
- [ ] QR-код даёт правильные реквизиты для оплаты
- [ ] Переход по ссылке на банковский сервис происходит без ошибок (сервис доступен) и подставляет правильные реквизиты для оплаты
