# REQ-007 — Пользователь просматривает юридическую и контактную информацию

**Статус:** draft  
**Контур:** as-is

## Предварительные условия

Пользователь находится на сайте Car2me.ru (лендинг или связанная страница).

## Поведение

- Пользователю на лендинге доступны ссылки на:
  - публичную оферту (`offer.html`)
  - политику персональных данных (`privacy.html`)
  - согласие на обработку ПДн (`pd-consent.html`)
- Пользователь может открыть каждый документ и прочитать его
- Пользователь видит контакт для связи: email `hello@car2me.ru`
- Пользователь видит идентификацию исполнителя (ФИО, статус самозанятой, ИНН) в зоне, связанной с оплатой/подвалом сайта
- В блоке оплаты явно указано, что оплата означает принятие оферты; обработка данных формы — по политике ПДн; перед отправкой формы нужно согласие

## Acceptance criteria

- [ ] С лендинга открываются без ошибки: `offer.html`, `privacy.html`, `pd-consent.html`
- [ ] На лендинге или в подвале указан email `hello@car2me.ru` (кликабельный mailto)
- [ ] Указаны ФИО исполнителя, самозанятость и ИНН
- [ ] Рядом с оплатой / формой есть ссылки на оферту, политику ПДн и согласие
