# REQ-005 — Пользователь заполняет форму

**Статус:** draft  
**Контур:** mixed — форма/гейты as-is (Яндекс.Формы); thank-you редирект — **to-be** ([REQ-006](REQ-006.md))

## Предварительные условия

Пользователь находится на сайте и видит форму (или переход к ней).

## Поведение

### As-is

- Пользователь приступает к заполнению формы (Яндекс.Формы)
- Система в обязательном порядке запрашивает: документ об оплате, email, имя, согласие на обработку перс. данных
- Пользователь выполняет эти действия
- Только после этого система позволяет перейти к основной части формы
- Пользователь заполняет форму и отправляет её

### To-be

- После отправки пользователь перенаправляется на thank-you page на сайте ([REQ-006](REQ-006.md) — страницу ещё нужно создать)

## Acceptance criteria

### As-is

- [ ] Основная часть формы со сбором данных недоступна, пока не выполнены условия: файл об оплате, email, имя, согласие на обработку ПДн
- [ ] Форму можно успешно отправить после выполнения условий

### To-be

- [ ] После заполнения формы пользователь автоматически попадает на thank-you page сайта
