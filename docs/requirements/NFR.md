# NFR — нефункциональные требования (весь сайт)

Общие ограничения и качества Car2me.ru. Индекс: `NFR-NNN` (отдельно от `REQ-NNN`).

Формат записи:

```markdown
## NFR-NNN — название

**Статус:** draft | accepted

### Требование
…

### Acceptance criteria
- [ ] …
```

## NFR-001 — Адаптивное отображение (web и mobile)

### Acceptance criteria

- [ ] Контент и основные действия доступны и читаемы на десктопе
- [ ] Контент и основные действия доступны и читаемы на планшете
- [ ] Контент и основные действия доступны и читаемы на телефоне
