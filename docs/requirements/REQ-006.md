# REQ-006 — Пользователь просматривает thank-you page

**Статус:** draft  
**Контур:** to-be (страницы ещё нет; редирект с Яндекс.Формы — настроить)

Не путать с текущим контуром: сейчас после формы thank-you page сайта нет.

## Предварительные условия

Пользователь отправил Яндекс Форму; настроен редирект на thank-you page сайта.

## Поведение

- Пользователь автоматически перенаправлен на thank-you page
- Сработала цель метрики «Форма заполнена» (при согласованной модели из [REQ-002](REQ-002.md) / [REQ-003](REQ-003.md))
- Пользователь видит на странице: благодарность, информирование о сроках оказания сервиса

## Acceptance criteria

- [ ] После заполнения формы редирект на thank-you page происходит автоматически
- [ ] Страница с фиксированным URL и запретом индексации (`noindex` / эквивалент) — не попадает в поиск
- [ ] Прямое открытие URL страницы допустимо; отдельной «одноразовой» ссылки без постоянного адреса не требуется
