# Requirements

Короткие требования текущего контура Car2Me (не Carapis).

## Нумерация (раздельные индексы)

| Тип | Префикс | Где живёт | Пример |
|-----|---------|-----------|--------|
| Функциональные | `REQ-NNN` | отдельные файлы `REQ-NNN.md` | `REQ-001` |
| Нефункциональные | `NFR-NNN` | общий список [NFR.md](NFR.md) | `NFR-001` |

Счётчики **не пересекаются**: `REQ-001` и `NFR-001` — разные требования.

## Функциональные (REQ)

Формат файла: `REQ-NNN.md`

```markdown
# REQ-NNN — название

**Статус:** draft | accepted  
**Контур:** as-is | to-be | mixed

## Поведение
…

## Acceptance criteria
- [ ] …
```

Поле **Контур** отделяет текущую реальность сайта от желаемого (чтобы не путать тест гипотез с продом).

Операционный контур «админ собрал отчёт в Cursor» в REQ сайта **не входит** — это другой контур; при необходимости позже `REQ-008` (ops).
