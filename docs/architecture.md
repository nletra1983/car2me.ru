# Архитектура Car2Me (as-is)

**Дата:** 2026-09-06  
**Статус:** черновик · контекстная схема  
**Диаграмма:** [Architecture AS IS.drawio](Architecture%20AS%20IS.drawio) (C4 Context)

## Участники на схеме (контекст)

| Роль / система | Тип | Назначение |
|----------------|-----|------------|
| Пользователь | Person | Подбор модели через Car2Me |
| Администратор | Person | Заявки, отчёты, отправка клиенту |
| Car2me.ru | Web-site | Лендинг и приём заявок |
| Платежная система | External | Оплата услуг |
| Яндекс-формы | System | Приём ответов опроса |
| Cursor | System | Формирование отчёта |
| E-mail | System | Доставка ответа пользователю |
| Яндекс-директ (Поиск + РСЯ) | External | Трафик |
| Яндекс-метрика | External | Веб-аналитика |

## Описание процесса (своими словами)

1. **Администратор** создаёт лендинг, настраивает Яндекс-Формы, Яндекс Директ и Яндекс Метрику и интегрирует эти системы между собой.
2. **Пользователь** пользуется Яндексом и видит объявления в поиске или в РСЯ, переходит на сайт Car2me, читает информацию, оплачивает услугу через банк и заполняет Яндекс.Форму.
3. **Администратор** проверяет наличие новых ответов в Яндекс-форме и соответствующих платежей в платёжной системе, с помощью Cursor генерирует отчёт и отправляет его пользователю по email.

## Checklist as-is

Ответы на уточняющие вопросы по текущему контуру.

### 1. Откуда трафик?

**Яндекс-Поиск + РСЯ.**

### 2. Что на сайте является продуктом?

Продуктом является **отчёт** и сам **контент на лендинге**.

### 3. Оплата: как узнаю, что оплатили?

Смотрю историю поступающих платежей в личном кабинете **Сбербанк**.

### 4. Форма: куда ответы?

Ответы смотрю в **Яндекс.Формах**, скачиваю в формате **.csv**, сохраняю в папку на компьютере с ответами. В Git это **не** идёт.

### 5. Шаги до отчёта

Говорю Cursor, что есть новые ответы и нужно сгенерировать новые отчёты. Cursor использует скиллы по созданию отчётов и генерирует отчёт.

### 6. Сайт Car2me: как создаю и публикую?

Сайт создаю через **Cursor** и через него же отправляю в **GitHub**.
