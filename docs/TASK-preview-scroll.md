## Зачем

В Вебвизоре люди смотрят скрин матрицы (`content/preview.png`), зумят **весь сайт** (запись кривая) и скроллят. PDF часто не качают. Сейчас картинка сжата в ширину колонки (`width: 100%`), поэтому ячейки не прочитать внутренним скроллом.

Нужно: читать таблицу, двигая картинку **внутри** окна с рваным краем. В Метрике — визиты, где так сделали, отдельно от скачивания PDF.

## Для пользователя

- Блок «Пример отчёта» тот же (рамка, рваный край, ссылки на PDF).
- Картинка **крупная**, в своей ширине (~1508px), не сплющенная под сайт.
- Ячейки читаются скроллом/перетаскиванием **внутри рамки** (горизонталь и вертикаль). Зум всей страницы не нужен.
- Ссылки «Смотреть полный пример» / PDF / `download` / цель `cta_case` — **без изменений**.

## Метрика

Новая JS-цель **`preview_scroll`**: один раз за визит, когда пользователь сам поскроллил `#report-preview-scroll`.

- Не считать программный скролл при загрузке (`centerPreview` внизу `index.html`).
- Не считать скролл страницы.
- `cta_case` не менять и не подменять этой целью.
- В комментарии `metrika.js` дописать идентификатор.
- В кабинете Метрики цель не создаётся кодом — после выкладки пользователю: тип «JavaScript-событие», идентификатор `preview_scroll`.

## Как делать

- Файлы: `index.html` (CSS/разметка превью), `metrika.js`.
- Картинка: натуральная ширина (как у файла 1508×948), контейнер как сейчас с `overflow` и ограниченной высотой.
- Слушатель `scroll` на `#report-preview-scroll`, порог чтобы не сработал от центрирования при load.
- Существующий UX рамки/масок не ломать без нужды.

## Не делать

- Лайтбокс, щипок, кнопки «крупнее», PDF.js, iframe PDF.
- Параметры визита «блок выхода», новые `section_*`, правки кейса / `#order`.
- «Чтобы Вебвизор показывал документ» — невозможно, не пытаться.
- Снимать `download` у PDF.

- [ ] На узком экране матрица не сжата в ширину сайта; внутри рамки можно проскроллить по горизонтали и вертикали и прочитать ячейки.
- [ ] Автоскролл при загрузке **не** шлёт `preview_scroll`; ручной скролл превью — шлёт один раз.
- [ ] Клик по PDF по-прежнему `cta_case`.
