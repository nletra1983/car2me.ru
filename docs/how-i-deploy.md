# Как я деплою (своими словами)

Краткий личный цикл. Подробности инфраструктуры (Pages, DNS, SSL) — в [DEPLOY-MANUAL.md](../DEPLOY-MANUAL.md).

## Цикл

1. Перехожу в каталог проекта: `d:\car2me-site`
2. Смотрю статус: `git status`  
   По идее ветка **up to date** с remote, плюс список того, чего ещё нет в git (или что изменено).
3. Добавляю по очереди нужные папки и файлы:  
   `git add путь`
4. Если что-то добавила случайно — убираю из индекса:  
   `git restore --staged путь`
5. Коммит с комментарием (если нужно):  
   `git commit -m "комментарий"`
6. Отправляю на GitHub:  
   `git push`

После push GitHub Pages обновляет https://car2me.ru (обычно 1–2 минуты). Затем — [smoke-checklist](qa/smoke-checklist.md).

## Напоминание

Не добавлять в git зону B (ответы клиентов, рабочие отчёты, ПДн) — см. [README.md](README.md).
